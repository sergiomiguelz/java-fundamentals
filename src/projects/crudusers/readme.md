# CRUD de Usuários no Console (Java)

Este projeto é um sistema simples de CRUD (Create, Read, Update, Delete) de usuários executado via console, desenvolvido em Java com foco em Programação Orientada a Objetos.

---

## 📌 Funcionalidades

- Cadastro de usuários
- Listagem de usuários
- Busca por ID
- Atualização de dados do usuário
- Remoção de usuários
- Validação básica de dados
- Tratamento de exceções no menu e entrada de dados

---

## 🧠 Tecnologias utilizadas

- Java
- ArrayList
- Scanner (entrada via console)
- Programação Orientada a Objetos (POO)

---

## 🏗 Estrutura do projeto

- `Usuario` → classe modelo (id, nome, email)
- `UsuarioService` → lógica de CRUD e armazenamento em memória
- `Main` → interface com o usuário via console
